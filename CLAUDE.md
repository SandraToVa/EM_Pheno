## Project

Phenomenology (Sec. 5) of the *EM Transitions Notes* (Sandra Tomàs): E1 transitions of quarkonium and
hybrid -> quarkonium + photon in the BOEFT, with LEFs matched to the effective string theory (EST).

* Code: this repo (`python/emlib`, driver scripts in `python/`, tests in `tests/`, outputs in `results/`, `figures/`).
* Text: outside the repo, `../TeX file/tex_pheno/` (`sec_pheno.tex`, `app_codes.tex`, `pheno_standalone.tex`; the
  table bodies `tab_*.tex` and the figures `fig_*.pdf` there are generated by the scripts, never edited by hand).
  The main notes are `../TeX file/mainEM.tex` (equation labels used by the code docstrings, e.g. `eq:lab_vertex`).
* References: `../Ref/` (lattice hybrid data: `../Ref/arXiv-0902.2241v1`, Dudek et al. 2009; model: `2610.22088`).

## How to run (from `python/`)

```
python3 run_all.py && python3 run_hybrids.py
python3 make_tables.py && python3 make_hybrid_tables.py && python3 make_figures.py
python3 ../tests/test_e1.py && python3 ../tests/test_hybrid.py     # both must end with ALL PASS
```
Then compile `../TeX file/tex_pheno/pheno_standalone.tex` (pdflatex, bibtex, pdflatex x2; needs `../mainEM.aux`).

## Conventions

* Every number in the text comes from `results/` or a generated table; quote them from `results/*.json|csv`.
* Model choices are Sandra's: do not change the physics (LEFs, flavour relations, error treatment, data sets)

* Units: GeV, GeV^-1 for r; widths in keV in the outputs. `e = sqrt(4 pi alpha)`; charges e_c = 2/3, e_b = -1/3.

## Current state (v12, Nov 18 2026)

* Quarkonium (v11): `g_E1(r) = e r [e_Q + (A_Q r + kappa_Q x)/(1 + x)]`, `x = (r/r0)^2`, `r0 = 1.58 GeV^-1`, 1/m
  corrections, `A_c = -A_b/2`, `kappa_c = -kappa_b/2`. `sigma_th = 2 eps Gamma` (model width), eps = 0.3 (c),
  0.1 (b). Errors: fits to data +- sigma_exp (Eq. eq:exp_range), not Delta chi^2 = 1. Reference NL core:
  `A_b = -0.059`, `kappa_b = +0.046` (`kappa_c = -0.0231`).
* Hybrids (v12), LOCAL form only: each LEF `g_X(r) = e [B_Q r delta_X,mag + kappa_Q ghat_X(r) x]/(1 + x)`
  (Eq. eq:gH_interp): magnetic LEFs (g_B_perp, g_B_par) get the short-distance term `B_Q r`; electric LEFs
  (g_E_par, g_E_perp, g_E^Sigma) only the long-distance EST shape. `kappa_Q` = quarkonium value; `B_c` fitted to
  the quenched lattice widths 42(18) and 115(16) keV; `B_b = -2 B_c`. Same theory error and error method as
  quarkonium. Result: `B_c = -0.186` (chi^2 1.4/1), other branch `+0.120`.
* Open: the non-local (NL) form of the interpolated LEFs is not defined yet (`nonloc=True` raises
  `NotImplementedError`); g_B_par -> e (B_Q - (24/pi) kappa_Q) r at r -> 0 (not exactly e B_Q r); the ratio
  Gamma(eta_c1)/Gamma(Y) = 0.6-0.7 vs lattice 2.7 +- 1.2; flavour scaling of B_Q (1/e_Q vs e_Q) decides bottom.
